; Z80 ICE command line instructions to identity-fill the MMU mapping RAMs for 
; task_id=0, bank=0 and enable the MMU.
; The Z80 has only 16 x 4KB pages (page_index 0-15) in its 64K address space, 
; so a single task/bank context covers the whole space; page_frame is set equal 
; to page_index for each page (RAM1=page_index, RAM2=0 -> no protection bits).

; Port layout verified against CPLD/Xilinx ISE/src/MemController.vhd (io_latch_*
; select the cell during programming; MAP[3:0] comes from A[15:12], hardwired
; on the PCB to the SRAM address pins, not from any CPLD latch).

; Also loads the normal (non-IO) latches with the same task_id=0/bank=0, since
; those - not the IO latches - drive MMU_MAP once ram_ce_en enables the RAMs
; for ordinary CPU memory cycles, so code can actually execute through the
; freshly identity-mapped pages.
